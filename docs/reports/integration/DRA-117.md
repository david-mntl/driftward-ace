## Decisions
- **Load order:** `load_tuning()`, then `load_graze_rules()`, then `load_wave_book()`, then the spawn list. The contract puts the graze load "right after `load_tuning()`", and the check wants the `scoring loaded` line right after `tuning loaded`. Source: frame-loop.md, Rules (DRA-117); integration-checks/DRA-117.md.
- **Draw order:** the rings are drawn for each ring in `run.graze_rings`, right after the ship's place, on every frame whatever `run.ship_visible` is. They come before the debug overlay, the Game Over box and the HUD. Source: frame-loop.md, Rules (Draw, Graze rings over the ship); release.md (DRA-117 calls).
- **Scoring loader:** `check_fields` with every field optional. Then a check per field: `graze_points` an int ≥ 0; `graze_popup_ticks`, `graze_ring_ticks` and `graze_ring_width` ints ≥ 1 (`check_integer`); `graze_popup_rise_per_tick` a number ≥ 0; the two diameters numbers > 0 (`check_positive`). A bool is never accepted. Defaults are the `DEFAULT_GRAZE_*` constants imported from `core.graze`, and the loader keeps no copy. Floats are built with `float(...)`, as the contract lists. Source: tuning-loader.md, Rules (Scoring file); scoring.schema.json.
- **Hazards file:** `graze_margin` uses `check_positive`, with default `GRAZE_MARGIN` from `core.drifters.base`, and goes to `HazardRules(graze_margin=float(...))`. Source: tuning-loader.md, Rules (Hazards file); hazards.schema.json.
- **Shared checks reused** from `app.drifters.checks`, so each field rule has one home and the messages match the other files. Source: systems/app/general.md, Interface.
- **Loop unchanged:** the fixed 60 Hz accumulator, one `step_run` per tick and `await asyncio.sleep(0)` each frame. A retry keeps `graze_rules` inside core, so the app never calls `start_run` again. Source: 15-tech-constraints.md, rules 1 and 2; frame-loop.md.
- **Logging:** two INFO lines at startup (`tuning loaded`, `scoring loaded`) and nothing per tick. Source: game/CONTEXT.md, Logging; tuning-loader.md.
- **Spawn list switched for the run only,** as the Director allowed. The original file was saved to the scratchpad first and restored after. Source: integration-checks/DRA-117.md; main session's handoff.
