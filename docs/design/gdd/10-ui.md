## Summary
The HUD keeps the score, lives, level and grazes in view at all times. The menu leads to the run, the instructions and the leaderboard. The pause box shows while the game is paused. The game-over screen shows the result and how to retry. Every hazard warning on screen is part of the hazard's spec, not the HUD.

```
+--------------------------------+
| SCORE 1234          ♥ ♥ ♥      |
| LV 2   GRAZE 5                 |
|                                |
```

## Rules
1. The HUD draws on top of everything and never covers the top line area so much that it hides a warning. Exact margins: UI-01.
2. HUD shows: SCORE (top-left), lives (top-right), level and grazes (below the score). BEST appears next to SCORE once the top 10 has an entry ([11-save-data.md](11-save-data.md)).
3. While invulnerable, the ship blinks ([05-lives-and-damage.md](05-lives-and-damage.md)).
4. **Life-lost feedback** (screen flash, HUD life breaks, ship burst and rebuild) is defined in [05-lives-and-damage.md](05-lives-and-damage.md) rule 3. Its look and timings live here once set: LD-08.
5. The UI only reads game state. It never changes it.
6. All in-game text uses a direct, human voice. Short sentences, no filler, no hype. Source: Director.
7. **Debug overlay.** Exists only in debug mode ([15-tech-constraints.md](15-tech-constraints.md) rule 7). It only reads game state, like the HUD. In normal mode it never shows and F3 does nothing. In debug mode a debug setting chooses what plays: the normal waves or the test spawn list (the list when left out).
8. **Error screen.** Replaces the game when an unexpected error stops it. The game doesn't resume; the player reloads the page.
9. **Screens.** When each screen shows and which keys it takes: [02-game-flow.md](02-game-flow.md). The content of each is fixed above; the exact text and look wait for UI-03 and UI-04.
10. **Game-over message.** Only the message for the run's place shows ([11-save-data.md](11-save-data.md) rule 10). A score off the list never says it made the top 10 or is a new best.

## Edge cases
- Very large scores: the HUD must not overlap the lives display. Max digits: UI-01.

## How to extend
A new HUD element needs a position, the game state it reads, and its update rule. If the game doesn't track that state yet, adding it is a game-logic change, not a UI one.
